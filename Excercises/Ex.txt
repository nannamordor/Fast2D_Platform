Currently the Program class and the Main method is full of things:

This is not ideal. Main is just our entry point and the cleaner it is the better. 
Let's create a new class called Game. Game contains the following variables. 
Window window;
Player player;
Use correct naming convention for the variables OBV! 

Main method needs to be like this

static void Main(string[] args)
{
    Game game = new Game(800, 600, "MyGame");
    game.Update();
}

As you can see we are now just creating the Game class in Main and we are passing the window size and title.
everything else needs to be handled inside the Game class.
